# SOP - Tournage démos Mode Examen

Source: `[C] Guide Tournage Demos - Etat Reel au 1er Aout`, MAJ 10 août.

Règle: Focus ne bloque plus rien. Toute démo de blocage doit partir du Mode Examen.

## D02 - Blocage

1. Assistant -> Mode Examen -> Démarrer le mode examen.
2. Choisir TikTok/Instagram dans "Choisir les applications".
3. Durée 25 min.
4. Activer "Bloquer les applications".
5. Démarrer.
6. Sortir de l'app, ouvrir TikTok.
7. Filmer le bouclier et le retour aux révisions.

## D09 - Dynamic Island

1. Utiliser la même session que D02.
2. Sortir de l'app.
3. Montrer le compte à rebours dans la Dynamic Island.
4. Ouvrir TikTok avec le bouclier toujours visible.
5. Maintenir Dynamic Island pour l'ouvrir en grand.

## D05 - Replanification

1. Créer 3 tâches sur hier.
2. En cocher 2.
3. Laisser 1 non faite.
4. Ouvrir Tâches.
5. Filmer la bannière ambre.
6. Ouvrir la proposition.
7. Filmer l'ancien jour barré, nouveau jour, barres de charge.
8. Appuyer sur Replanifier.
