# SOP - Micro-influenceurs

Source: SOPs Noah + Répartition tâches.

1. Construire une liste de 10-15 créateurs qualifiés.
2. Critères minimum:
   - audience étudiante/PACES/L.AS ;
   - vues récentes cohérentes ;
   - ton compatible ;
   - tarif possible.
3. DM court:
   - vidéo/sujet vu ;
   - productif.io en une phrase ;
   - proposition d'appel 10 min.
4. Relance une fois après 48h.
5. Call 10-15 min:
   - montrer l'app ;
   - demander tarif ;
   - négocier légèrement ;
   - décision sur le call.
6. Documenter deal, tarif, deadline, statut.
