# SOP - Page SEO Alternative à X

Source: Répartition tâches Phase 2.

1. Choisir l'angle: alternative à Reclaim/Motion pour étudiants.
2. Comparer sur critères étudiants:
   - examens ;
   - chapitres ;
   - blocage téléphone ;
   - simplicité ;
   - prix.
3. Écrire une page utile, pas une page de comparaison agressive.
4. Publier.
5. Vérifier liens, title, meta description, indexabilité.
6. Preuve attendue: URL publiée.
